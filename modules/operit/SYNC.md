## 5. 上游更新套用操作手册（每次 0.5~2 天）

1. `git -C autojs_ai_code/Operit fetch && git log f1bbcd80..<NEW> --oneline -- app/ quickjs/`。
2. 逐文件 diff：命中 A 类 → 原样套到 `modules/operit/src/...`；命中 B/C 类 → 查 §6 对应条目的改造说明后人工对账；触及 hostcompat 接口 → 查 §2 D 类接线。
